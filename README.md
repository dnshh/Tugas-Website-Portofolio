Tampilan web portofolio yang saya buat, tampilan ini dibuat dengan menerapkan HTML sebagai kerangka code, CSS untuk mendesain atau mempercantik tampilan, dan JS untuk memberikan logika aplikasi agar lebih responsif. Pada bagian HTML saya menggunakan banyak section untuk mengelompokkan code yang berguna pada suatu tampilan tertentu dan menandai section tersebut dengan class. pada body, saya menerapkan penggunaan header, footer, hingga nav. pada CSS, saya membuat web agar support pada tampilan mobile dan desktop dengan @media. agar terlihat lebih menarik,  pada JS saya coba membuat sebuah perkondisian untuk bagian salam agar sesuai dengan waktu saat dibuka, dan menambahkan tombol ke atas untuk balik ke halaman bagian atas.
